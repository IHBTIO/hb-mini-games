# 🎮 HB Mini Games

A collection of classic browser games I built as coding practice with AI assistance. Lightweight, no dependencies — just open the HTML files and play.

## 🕹️ Games Included

| Game | Description |
|------|-------------|
| **Flight Chess (飞行棋)** | Classic board game with dice-rolling mechanics |
| **Gomoku (五子棋)** | Five-in-a-row on a 15×15 board, two-player |
| **Schulte Table (舒尔特表格)** | Focus training — find numbers from 1 to 25 in order |
| **Digital Huarong (数字华容道)** | 4×4 sliding puzzle, rearrange numbers into order |

## 🚀 How to Play

1. Download or clone this repository
2. Open any `.html` file directly in your browser
3. No server, no installation — just double-click

## 🛠️ Tech Stack

- **Pure HTML + CSS + JavaScript** — no frameworks, no libraries
- All logic is client-side, no data is sent anywhere

## 📝 Notes

- These are **practice projects**, not production-ready software
- Game rules are kept classic and simple
- Some visual designs are generated with AI assistance
